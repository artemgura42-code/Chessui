CHESS VISION — ИСПРАВЛЕНИЕ РАСПОЗНАВАНИЯ

В этом архиве находятся три полных Kotlin-файла для замены:

app/src/main/java/app/chessvision/BoardVision.kt
app/src/main/java/app/chessvision/CaptureService.kt
app/src/main/java/app/chessvision/MainActivity.kt

Что исправлено:
1. В BoardVision.kt устранено сравнение нормализованной разницы яркости с числом 40. Теперь используется порог 0.04 в той же нормализованной шкале.
2. Добавлена диагностика: количество распознанных фигур, количество фигур в верхних/нижних двух рядах и в центре доски.
3. CaptureService.kt выводит причину, по которой обучение ещё не началось, и показывает количество сомнительных клеток после обучения.
4. MainActivity.kt показывает версию интерфейса 1.3 и краткую инструкцию первого запуска.

ЗАМЕНА:
Замените каждый файл в репозитории GitHub по точно такому же пути. Не создавайте файлы с суффиксами (1), (2) и не кладите Kotlin-файлы в корень проекта.
После трёх замен запустите GitHub Actions → Build Chess Vision APK.
Скачайте новый артефакт и установите APK из него.

Важно:
Это исправление устраняет найденную ошибку проверки контраста и добавляет диагностику обнаружения фигур. Оно не гарантирует безошибочное распознавание на любой теме доски. Полную Android-сборку и проверку на реальном телефоне после замены необходимо выполнить через GitHub Actions и устройство.
